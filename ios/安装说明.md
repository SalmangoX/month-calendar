# 节律 iPhone 版：安装说明

iPhone 版不上 App Store，用 **AltStore** 或 **SideStore** 安装：它们用你自己的 Apple ID（免费的就行）给 App 签名，并在后台自动续期，不用每 7 天手动重装。

- 需要 iOS 26 或更新版本。
- 第一次安装要在 iPhone 上打开「开发者模式」：设置 → 隐私与安全性 → 开发者模式（第一次装完侧载的 App 后才会出现这个开关），打开后重启。
- 免费 Apple ID 同一时间最多装 3 个这类 App（AltStore / SideStore 自己占一个）。

## 方法一：AltStore（需要这台 Mac）

1. 在 Mac 上安装 AltServer：<https://altstore.io>，打开后菜单栏会出现它的图标。
2. iPhone 用数据线连上 Mac，在「访达」里勾选「通过 Wi-Fi 显示这台 iPhone」。
3. 菜单栏 AltServer → Install AltStore → 选你的 iPhone，输入 Apple ID 安装 AltStore。
4. iPhone 上：设置 → 通用 → VPN 与设备管理 → 信任你的 Apple ID。
5. 打开 AltStore → Sources（源）→ 右上角 + → 粘贴下面的源地址 → 找到「节律」→ 安装：

   ```
   https://cdn.jsdelivr.net/gh/SalmangoX/month-calendar@dist-ios/source.json
   ```

以后：Mac 开着 AltServer、和 iPhone 在同一个 Wi-Fi 时会自动续期；有新版本时 AltStore 的「更新」里会提示。

## 方法二：SideStore（装好后不再需要电脑）

1. 按 <https://sidestore.io> 的说明安装 SideStore（第一次要用一下电脑）。
2. 打开 SideStore → Sources → + → 粘贴上面同一个源地址 → 安装「节律」。

以后在手机上自己续期，不需要电脑。

## 只想装这一次

也可以直接下载安装包，在 AltStore / SideStore 里选「+」打开它：

```
https://cdn.jsdelivr.net/gh/SalmangoX/month-calendar@dist-ios/Cadence.ipa
```

## 开发者：打包和发布

```bash
bash ios/build.sh sim     # 只编译模拟器版，检查能不能编译过
bash ios/build.sh         # 打包 ios/build/节律-<版本>.ipa（不签名，安装时由 AltStore / SideStore 签名）
bash ios/publish-ipa.sh   # 推到 dist-ios 分支（只留最新一个）并更新 AltStore 源
```

改了 iPhone 原生代码（ios/App，或者 Mac 共用的 Engine、CloudSync、GlassNav）要把 ios/version.json 的 build 加一；只改网页不用重新打包。
